# Layout presets

These JSON files ship inside the app (imported by `src/presets.ts`). They are
generated by `npm run gen:layouts` from pitch lists in
`scripts/gen-layouts.mjs`; edit the script, regenerate, and review the diff.

Format: see `DESIGN.md` §4.1. Pitches are MIDI (C4 = 60). Labels are what is
printed on the tine; octave dots are stored separately and drawn.

## standard-17

C4 to E6 in the usual fan: the lowest note in the centre, then alternating
left, right outward. Left to right: D6 B5 G5 E5 C5 A4 F4 D4 **C4** E4 G4 B4
D5 F5 A5 C6 E6.

## standard-21

The 17-key with F3, G3, A3 and B3 added in the centre. The outer 17 tines are
in exactly the 17-key positions, so 17-key tabs read the same.

## hluru-34 — DRAFT, built from the maker's description

Two tiers. Bottom: the standard 17-key fan. Top: one tine over each fan
tine, a semitone above it: the sharp for C, D, F, G and A, and for E and B,
which have no sharp, the natural above (F or C), so F4, C5, F5 and C6 exist
twice. This is what Hluru's own description of the instrument says; nobody
has checked it against one yet, hence the draft flag.

## chill-angels-46 — DRAFT, verify against the instrument

Transcribed from the product diagram. The reading below is internally
consistent (it sums to 46, covers every semitone from C3 to F6, and the four
duplicated naturals are exactly the four digits the diagram prints in blue),
but it has not been checked against the physical instrument.

Tiers from the bottom (against the soundboard) upward:

**Tier 0, bass (12):** the octave below the fan, naturals then sharps, `v` =
dot below. Aligned by column so that `1v` (C3) sits under the fan's `1` (C4)
and the sharps tier's `1#` (C♯4), which puts the row in slots 2 to 13:

```
7v  6v  5v  4v  3v  2v  1v  1v#  2v#  4v#  5v#  6v#
```

**Tier 1, main (17):** the standard 17-key fan.

**Tier 2, sharps (17):** one tine over each fan tine, one semitone above it.
For C, D, F, G and A that is the sharp; for E and B, which have no sharp, it
is the natural above (F or C), which the diagram prints in blue. Left to
right, `^` = dot above, `^^` = two dots:

```
2^^#  1^^  5^#  4^  1^#  6#  4#  2#  1#  4  5#  1^  2^#  4^#  6^#  1^^#  4^^
```

Tier order and the bass row's column alignment were confirmed by the owner
from memory on 2026-09-06. Still to confirm with the instrument in hand:

1. That every tine's label matches, in particular whether any accidental is
   printed as a flat rather than a sharp.
2. That the bass row's sharps are ordered `1# 2# 4# 5# 6#` left to right as
   the diagram shows.

When you have the kalimba, open Kalimba → Manage…, copy this preset, fix
anything wrong on the board, tick "checked against the instrument", and
save. Send the resulting `.layout.json` (Reveal shows it) so the preset in
`scripts/gen-layouts.mjs` can be corrected and `"draft": true` removed.
